Neon Coast Cover Studio is an offline web app that turns your own photos and a caption into multi-panel, GTA-poster-style cover art — no uploads, no server, no watermark; everything happens on canvas in your browser. Pick from five layouts (a nine-panel cover grid with a title block, a classic four-panel, a hero-and-three, a full-bleed single, and a tilted snapshot stack), drop in several photos, click any panel to select it, drag to reposition the shot inside it and zoom with a slider, or let one photo fill every panel. Each photo is run through a gradient-map colour grade computed pixel by pixel — Sunset Strip, Neon Nights, Teal & Orange, or Noir — then finished with adjustable film grain and a vignette so the panels hang together like one printed poster. Captions are lettered in heavy display type (Anton, with Pacifico for the subtitle, both SIL Open Font License and vendored locally) with outline, shadow and a sunset gradient fill, and the finished cover exports as a PNG at exactly 1080×1080, 1080×1350 or 1920×1080. Four demo photos are bundled (two made for make.fun, two drawn for this entry) so the studio produces a cover the moment it opens, and deterministic `?shot=` URLs render reproducible covers for screenshots. All artwork, code and lettering are original to this entry.

## Run it
```sh
node serve.ts
```
